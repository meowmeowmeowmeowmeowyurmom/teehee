# files/

Drop anything here that you want Claude to work on.

## How to use it from a tablet

1. Add or edit files in this folder on GitHub (the GitHub app or github.com in a browser):
   open the `files` folder, then **Add file → Upload files** or **Create new file**.
2. Open a Claude Code session on this repo (claude.ai/code or the Claude app) and say what you want,
   for example: "clean up the notes in files/" or "summarize files/report.pdf".
3. Claude edits the files and pushes to a branch, then opens a draft pull request.
4. Review the PR on your tablet. Merge it, or ask for changes.

## Tips

- Keep file names simple (no spaces is easiest).
- Don't put passwords, API keys or private data here. Anything pushed to GitHub is stored there.
- Large files (over about 50 MB) don't work well in a normal Git repo.
- One-off files can also be attached directly in the chat instead.
